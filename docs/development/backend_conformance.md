# BACKEND CONFORMANCE SUITE

## PURPOSE

THE SUITE CHECKS THAT THE ACTIVE MLX BACKEND SUPPORTS THE OPERATIONS THE DISK-KV RESTORE PATH REQUIRES. THE SUITE RUNS ON ANY DEVICE: CPU, METAL, OR ROCM. THE SUITE IS THE ACCEPTANCE GATE FOR THE MLX-ROCM PORT.

THE SUITE SEPARATES 2 KINDS OF PROBLEM:

- A BACKEND GAP: THE BACKEND LACKS A CAPABILITY. THE SUITE RECORDS `CAPABILITY-MISSING`.
- A RESTORE BUG: THE BACKEND HAS THE CAPABILITY, BUT THE OPERATION IS WRONG. THE SUITE RECORDS `FAIL`.

## RUN

```bash
python -m vllm_mlx.device.conformance
```

THE SUITE PROBES `mx.default_device()`. ON A LINUX CI HOST, THE DEVICE IS CPU. ON A MAC, THE DEVICE IS METAL. ON THE NEON GUEST, THE DEVICE IS ROCM.

### OUTPUT

THE SUITE PRINTS A TABLE TO STDOUT. EACH LINE IS 1 CHECK. THE STATUS IS 1 OF:

- `PASS`: THE CHECK PASSES.
- `FAIL`: THE CHECK FAILS. THIS IS A RESTORE BUG.
- `CAPABILITY-MISSING`: THE BACKEND LACKS THE CAPABILITY. THE DETAIL SAYS WHAT IS MISSING.

THE USER MAY ADD FLAGS:

- `--json FILE`: THE SUITE WRITES THE REPORT AS JSON TO FILE.
- `--gaps FILE`: THE SUITE READS A JSON LIST OF MORE DOCUMENTED GAP NAMES FROM FILE. A PORT USES THIS WHEN IT DOCUMENTS A NEW GAP.
- `--backend NAME`: THE SUITE SETS THE BACKEND NAME IN THE REPORT. THE DEFAULT IS THE NAME OF THE RESOLVED BACKEND, OR `NONE`.

### EXIT CODE

- `0`: ACCEPTED.
- `1`: NOT ACCEPTED.
- `2`: ERROR. FOR EXAMPLE, A GAPS FILE WITH A WRONG FORMAT.

## ACCEPTANCE

THE REPORT IS ACCEPTED WHEN ALL OF THE FOLLOWING ARE TRUE:

1. THE PROBES RAN. MLX IS IMPORTABLE.
2. THE REPORT HAS NO `FAIL` LINES.
3. EVERY `CAPABILITY-MISSING` LINE IS A DOCUMENTED GAP.

### DOCUMENTED GAPS

THE SUITE HAS A GAP LIST:

- `CPU`: `MEMORY_CAP_ENFORCEMENT`, `STREAM_OWNERSHIP`, `DEVICE_INFO.MEMORY_SIZE`, `DEVICE_INFO.MAX_RECOMMENDED_WORKING_SET_SIZE`.
- `GPU` (METAL, ROCM): NO DOCUMENTED GAPS.
- `UNKNOWN` DEVICE CLASS: NO DOCUMENTED GAPS.
- MLX NOT IMPORTABLE: EVERY CHECK NAME IS A DOCUMENTED GAP.

A PORT ADDS A GAP BY LISTING THE CHECK NAME IN A `--gaps` FILE.

## CHECKS

| NAME | WHAT THE CHECK DOES |
| --- | --- |
| `ENVIRONMENT.MLX` | THE SUITE IMPORTS MLX AND GETS THE DEFAULT DEVICE. |
| `ENVIRONMENT.MLX_LM` | THE SUITE IMPORTS MLX_LM. |
| `SEAM_CONTRACT` | THE SUITE CHECKS THAT THE DEVICE/BACKEND SEAM MATCHES: THE RESOLVED BACKEND, IF ANY, MATCHES THE DEVICE CLASS. THE CAPABILITIES THE BACKEND SAYS IT HAS MATCH THE API THE SUITE OBSERVES. |
| `MEMORY_CAP_ENFORCEMENT` | THE SUITE CHECKS THAT `MX.SET_MEMORY_LIMIT` EXISTS. THE SUITE RECORDS THE OBSERVED ALLOCATOR BEHAVIOUR AS 1 OF: `ENFORCED`, `HARD_FAIL`, OR `HINT`. |
| `QUANTIZED_KV_ROUNDTRIP` | THE SUITE CHECKS THAT `MX.QUANTIZE` AND `MX.DEQUANTIZE` GIVE THE SAME VALUES ON 2 CALLS WITH THE SAME INPUT. THE OUTPUT SHAPE EQUALS THE INPUT SHAPE. THE RESULTS HAVE NO NaN AND NO INFINITY. THE MAXIMUM DEVIATION IS WITHIN THE QUANTISATION STEP BOUND. IF MLX_LM IS PRESENT, THE SUITE CHECKS THAT A `QUANTIZEDKVCACHE` CHECKPOINT GIVES THE SAME BYTES AFTER A SAVE/LOAD ROUND-TRIP. |
| `PROMPT_CACHE_FORMAT` | THE SUITE CHECKS THAT `SAVE_PROMPT_CACHE` AND `LOAD_PROMPT_CACHE` KEEP THE CLASS IDENTITY AND THE VALUES. THE CLASS NAME IS STORED ON DISK. AN UNKNOWN CLASS NAME FAILS CLOSED. THE MODEL IDENTITY GUARD REJECTS WHEN THE VALUES DO NOT MATCH. |
| `STREAM_OWNERSHIP` | THE SUITE CHECKS THAT `MX.NEW_THREAD_LOCAL_STREAM` WORKS. THE DEFAULT STREAM IS REACHABLE FROM A 2ND THREAD. `SET_DEFAULT_STREAM` WORKS IN THE OWNER THREAD. |
| `COMPILE_THROUGH` | THE SUITE CHECKS THAT `MX.COMPILE` GIVES RESULTS EQUAL TO EAGER. THE RESULTS ARE THE SAME ACROSS 2 CALLS. THE PROBE USES A NEW `TMPDIR` DIRECTORY. |
| `ASYNC_EVAL` | THE SUITE CHECKS THAT `MX.ASYNC_EVAL` EVALUATES THE PENDING CHAIN IN ORDER. |
| `DEVICE_INFO.DEVICE_NAME` | THE SUITE CHECKS THAT `MX.DEVICE_INFO()` HAS A `DEVICE_NAME` OF TYPE `STR`. |
| `DEVICE_INFO.MEMORY_SIZE` | THE SUITE CHECKS THAT `MX.DEVICE_INFO()` HAS A `MEMORY_SIZE`. |
| `DEVICE_INFO.MAX_RECOMMENDED_WORKING_SET_SIZE` | THE SUITE CHECKS THAT `MX.DEVICE_INFO()` HAS A `MAX_RECOMMENDED_WORKING_SET_SIZE`. |

## MODEL IDENTITY GUARD

THE RESTORE PATH REJECTS A CHECKPOINT WHEN THE MODEL IDENTITY DOES NOT MATCH. THE PREDICATE IS `vllm_mlx.runtime.disk_kv_checkpoint.model_identity_matches`. THE PREDICATE RETURNS `FALSE` WHEN A VALUE IS `NONE` OR HAS NO VALUE, OR WHEN THE 2 STRINGS ARE NOT EQUAL. THE SCHEDULER GUARD AND THE SUITE USE THE SAME PREDICATE.

## HOST STATE

THE SUITE DOES NOT CHANGE HOST STATE IT DOES NOT OWN:

- THE COMPILE PROBE SETS `TMPDIR` TO A NEW DIRECTORY DURING THE PROBE. THE SUITE RESTORES `TMPDIR` AFTER THE PROBE.
- THE MEMORY-CAP PROBE RESETS THE LIMIT AFTER THE PROBE.
- TEMPORARY FILES ARE IN TEMPORARY DIRECTORIES. THE SUITE REMOVES THE DIRECTORIES.

## TESTS

`tests/test_conformance.py` TESTS THE REPORT ASSEMBLY, THE ACCEPTANCE RULE, THE GAP LIST, THE MODEL-IDENTITY PREDICATE, AND EACH PROBE AGAINST A FAKE MLX. THE SUITE IS TESTABLE WITHOUT MLX.
